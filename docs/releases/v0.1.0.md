# TSPack v0.1.0

## Status

- First public early release.
- Self-hosted after bootstrap.
- Intended for early dogfooding and evaluation, not production-critical workloads.
- CLI behavior, manifest shape, and generated artifacts may still change.

## Highlights

- Explicit `manifest.tsx` project contract.
- Deterministic `ts-lock.toml` resolved truth.
- Blocked-by-default dependency lifecycle scripts.
- Security acknowledgments and `doctor security` audit output.
- Lifecycle category classification and category acknowledgments.
- `check` and read-only `check --format`.
- RunTargets with runtime inheritance.
- Native xTest harness.
- `pack`, `why`, and `how` audit helpers.
- `outdated` reporting and targeted update safety.
- Declared UpdatePolicy with security-gated dry-run planning.
- Self-contained release binaries with embedded bridge assets.
- Unix install script.
- Self-hosting after bootstrap.

## Safety posture

- Lifecycle scripts are detected and blocked by default.
- Security policy is auditable through manifest acknowledgments, lockfile capabilities, and `doctor security`.
- UpdatePolicy planning is read-only in `update --policy --dry-run`.
- Policy-driven mutation is not implemented yet.

## Distribution

- GitHub Release artifacts are the canonical distribution surface for `v0.1.0`.
- Release artifacts include Linux, macOS, and Windows archives plus `checksums.txt`.
- `scripts/install.sh` installs Unix release archives from GitHub Releases and verifies checksums.
- The `setup-tspack` action implementation exists; hosted smoke is pending until after the first release exists.
- `get.tspack.dev` is not live.

## Known limitations

- Inspect/browser deep testing is deferred.
- No policy-driven update mutation.
- No targeted policy mutation planning.
- No Homebrew, mise, or npm bootstrapper yet.
- No `get.tspack.dev` hosted installer yet.
- No production-stability claim.

## Upgrade/install

After the `v0.1.0` tag is published, use GitHub Releases directly or run the install script from a trusted checkout or reviewed release URL:

```bash
TSPACK_VERSION=v0.1.0 sh scripts/install.sh
```

Then verify:

```bash
tspack --version
tspack check --help
```
