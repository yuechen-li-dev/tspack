# TSPack v0.1.3

TSPack v0.1.3 is a patch release focused on generated-project editor stability, safer materialization, run-target cleanup, inspect/browser reliability, and release-smoke-ready init templates.

## Highlights

- Fixed the manifest/editor TSX boundary for generated projects.
- Hardened dependency materialization against circular dependency and path-depth recursion.
- Fixed run-target cleanup and readiness races.
- Stabilized inspect/browser tests and deterministic Windows browser discovery.
- Added concept-aware inert init templates:
  - `static`
  - `react`
  - `react-library`
- Added the internal Template IR pipeline: `RawTemplate -> TemplateIR -> TemplatePlan -> ApplyPlan`.
- Made generated templates release-smoke-ready with project Biome tooling and lifecycle audit policy.
- Overhauled CLI help:
  - default `tspack` output is now semantic and workflow-oriented
  - command categories via `tspack help commands`
  - lifecycle guide via `tspack help workflow`
  - core concepts guide via `tspack help concepts`
  - command-specific semantic pages via `tspack help <command>`
  - `--help` / `-h` aliases for core commands
  - exhaustive reference remains available via `tspack help all`
  - `tspack init` prints template-aware next steps
  - removed old “M0 scaffold” wording

## Fixes

- `tspack init` generates `tsconfig.tspack.json`.
- Generated projects include local `tspack/manifest` declarations for editor typechecking.
- Manifest TSX typechecking no longer requires the React JSX runtime.
- App and library TypeScript configs exclude TSPack-owned manifest, xTest, and artifact paths.
- Circular dependency materialization no longer recursively expands paths.
- A materialization path-depth guard now reports `TSPACK_MATERIALIZE_PATH_DEPTH_EXCEEDED`.
- Run-target process cleanup no longer hangs on stdout/stderr pipes inherited by child or grandchild processes.
- Finite commands that emit readiness before exit are handled without false “exited before ready” failures.
- `inspect --json` failure output remains valid JSON.
- Windows Chromium and VS Code discovery are deterministic and testable through injected environment, filesystem, and platform inputs.
- Browser-required Playwright integration tests skip cleanly when Chromium is unavailable.
- Ordinary URL inspect does not leak VS Code discovery errors.
- The static template target now emits a non-empty types path.

## Templates

- `tspack init --template static`
- `tspack init --template react`
- `tspack init --template react-library`
- `tspack init --list-templates`
- Local templates via `--template ./path`

Templates are inert:

- no command execution
- no remote fetching
- no dependency installation during init

Built-in static, React app, React library, and local templates all use the same engine. Concepts are metadata only in v0.1.3; overlays and composition remain reserved for future Template IR work.

## Security

- Lifecycle scripts remain blocked by default.
- Generated templates acknowledge known lifecycle categories in tool closures.
- Lifecycle presence remains auditable through policy and security diagnostics.
- Generated `package.json` compatibility files contain no lifecycle scripts.

## Validation

The v0.1.3 release gate should run:

```sh
go test ./... -timeout 300s
npm --prefix manifest-frontend run build
npm --prefix manifest-frontend run typecheck:manifest-api
npm --prefix manifest-frontend test
npm --prefix extensions/tspack-vscode test
npm --prefix extensions/tspack-vscode run compile
./scripts/self-host-smoke.sh
./scripts/build-release.sh
```

Release preparation should also build the release archives, smoke at least the host archive, run generated-template smokes from the release binary, verify install/setup action references, and finish with `git diff --check` plus `git status --short`.

## Known notes

- Concept overlays are future work.
- Concepts are metadata in v0.1.3.
- Remote templates are not implemented.
- Lifecycle execution remains blocked by default.
- Some browser-required inspect integration tests skip when Playwright Chromium is unavailable.
- Do not tag, publish, or upload this release until the final release gate has passed and publication is explicitly approved.
